# English-Vocabulary-Learning-App
An Android application developed using Android Studio to help users improve their English vocabulary through an interactive and engaging learning experience. The app features a rich vocabulary database with images, colorful visual elements, and an intuitive interface designed to make learning new words more enjoyable and effective.

✨ Features

📚 Extensive English vocabulary database

🖼️ Image-based vocabulary learning

🎨 Colorful and visually engaging user interface

🔤 English words with meanings and translations

🧠 Interactive vocabulary learning experience

📱 Android mobile application

🌈 User-friendly design focused on making vocabulary learning less boring and more enjoyable

🛠️ Technologies Used

Android Studio

Java / Kotlin

Android UI Components

Vocabulary Database

Image-Based Learning

Developed as a university project with the goal of creating a more engaging, visual, and enjoyable way to learn and memorize English vocabulary.
